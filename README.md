# Volley Schemi

Applicazione web che mostra con animazioni come la squadra si muove in campo
nelle varie situazioni di gioco: ricezione, difesa sull'attacco avversario,
free ball, copertura dell'attacco, battuta e transizione.

Sistema di gioco 5-1. Pensata per essere aperta dal telefono con un link,
senza registrazione.

I macro requisiti sono in [docs/requisiti.md](docs/requisiti.md).

## Stato

In definizione: requisiti fissati, implementazione non ancora iniziata.
